# The gallery.
#
# Fifty anchors, chosen so the map can be CHECKED. A market map is judged on its
# most obviously wrong row, so these are markets where a reader already knows who
# the players are and will notice immediately if one is missing or invented.
# Obscure markets hide bad output; famous ones convict it.
#
# Spread across fifteen categories rather than fifty dev-tools companies, because
# a gallery that is all one shape reads as a tool that only works on one shape.
#
# Build with:
#   set -a && . ./.env && set +a && npx tsx scripts/batch.ts scripts/gallery-domains.txt
#
# Roughly $1.66 and 12 minutes a map at the rates in runs/, so about $83 and ten
# hours at the default two-at-a-time. Edit freely — one domain per line, # comments.
